# 丽影广场与丽影华庭街景重建

## 地图依据

2026-10-07 从 [OpenStreetMap 官方 API](https://api.openstreetmap.org/api/0.6/map.json?bbox=113.3125,23.0973,113.3185,23.1000) 读取四个商业区的楼体轮廓及商业用地边界。原始客村范围西界为 113.3155，经整栋过滤漏掉 B、C、D；新的建筑补丁保留 A 并补齐这三个分区。

| 分区 | OSM way | 地图高度信息 |
| --- | --- | --- |
| A | [543819178](https://www.openstreetmap.org/way/543819178) | 3 层，未标米制高度 |
| B | [369922823](https://www.openstreetmap.org/way/369922823) | 3 层，未标米制高度 |
| C | [543819176](https://www.openstreetmap.org/way/543819176) | 3 层，未标米制高度 |
| D | [543831480](https://www.openstreetmap.org/way/543831480) | 无高度或层数标签 |

商业用地使用 [relation 15927569](https://www.openstreetmap.org/relation/15927569) 的两段闭合外环。它决定石铺前场的范围，道路铺装仍优先于前场。三个原始入口节点也保存在补丁中。地下客村站的建筑没有变成地面楼体。

`scripts/import-liying-map.mjs` 从官方 API 的节点和 way 生成 `public/maps/liying.json`，记录源 URL、下载文件时间、SHA-256 及各元素版本和更新时间，不保存贡献者账号信息。原点沿用 `[113.3196, 23.0995]`；轮廓按既有投影保存到 0.01 米。此精度是数值保存精度，不代表实地测绘精度。

`withLiyingBuildings` 同步修正地图显示、模型基座、道路净距和 Rapier 碰撞使用的建筑数据；补丁不能覆盖道路或珠江数据，重复 A 区不会产生重叠建筑。使用其他地图原点时先还原经纬度再投影。

## 实景依据与估算范围

已实际查看的照片包括：

- [2022 年 C 区街角实景](https://imgwcs2.soufunimg.com/viewimage/house/2022_05/11/b56efe2f-98cf-4a08-9708-6f89311d1187/1400x933.jpg)：米黄色塔楼、窄竖向窗带、蓝灰玻璃裙楼、波浪饰带、竖向 C 区字牌，旁侧白色住宅及蓝色窗带。
- [高德上的苏宁门店沿街照片](https://aos-comment.amap.com/B00141R3OT/comment/content_media_external_file_100000744_1757576842866_12773515.jpg)：深色商场立面、亮白丽影广场与 LIVING Mall 字样、彩色标志及店铺雨棚。
- [去哪儿的沿街旧照片](https://tr-osdcp.qunarzz.com/tr-osd-tr-manager/img/d134c58dbc6acf8b480157d3c5e8f9dd.jpg)：浅蓝灰裙楼、白底金色字牌、米黄与粉褐住宅墙面、外凸框架及阳台窗栏。这张照片的拍摄日期无法核实。
- [丽影华庭历史项目页面](https://www.focus.cn/xf/gz-22002/)：用于核对新港中路 354 号和住宅项目身份，页面所示平面图目录没有提供完整、可核对的地理楼栋排布。

`liying.ts` 重建玻璃裙楼、沿街店铺与雨棚、标识、C 区波浪饰带、竖窗塔楼，以及白墙蓝色窗带、粉褐墙面和阳台层板。树列、弧形灯杆与铺装加入共享布局，布置时排除道路、建筑及已有设施。夜间复用几何和材质，通过店铺、标牌及部分住宅窗户发光表现亮灯；不逐窗创建实时光源。

**严格遵循地图的是地面轮廓、分区方位、商业边界和原始入口坐标。上部住宅的栋数、退台位置、各栋高度、层数、窗位以及树灯间距是照片比例估算。** 目前 B、D 各采用三段住宅体量，C 采用一段商业塔楼；这是渲染配置，不能当作已经核实的实际楼栋数量。A 保持低层商场体量，没有为它凭空添加住宅塔楼。估算上部体量限制在对应的真实基座之内，未创建虚构 OSM 楼栋 ID。三层裙楼按约 4.8 米层高建模，有明确米制高度时优先使用。

重点覆盖新港中路沿街可见部分；尚无完整航拍测量或全部住宅楼栋逐面的街景，不能称为全小区一比一测绘复刻。原始照片仅用于观察，不作为游戏贴图或分发资产。程序生成的三个小图集与全部材质、共享几何均在场景销毁时释放。

地图新增「丽影广场 · 新港中路」「丽影华庭 · 艺影街」两个导航点，以及两个游览视角；导航终点吸附到室外道路，不在楼体内部。

## 验证

2026-10-07：125 项街区单元测试通过。最终丽影模型专项及游览模块复测通过；Chrome 专项验证四个基座碰撞、C/B 间开放通道、石铺前场、树灯净距、室外导航终点、昼夜及 390 px 画面。既有 TIT 西门实际骑入和树灯、装置碰撞回归通过。

六个桌面游览截图无页面错误，最高 118 次绘制、28,724 个三角形；骑行视角与 C 区街角另行截图检查。场景按分区、视距及立面朝向裁剪，材质合批，不在昼夜切换时重建建筑。

类型检查、最终生产构建和原资源预算通过：首页入口 274.8 KiB、街区入口 286.3 KiB gzip，产物总量 11,290.6 KiB。构建中另修复了现有手柄死区参数被推断成常量类型的问题，仅补充 `number` 类型，配置值不变；其 5 项现有专项测试及丽影 3 项测试的最终复测通过。这些检查针对当前共享工作区；此前文档记录的全场景 90,000 三角形超限检查没有在本次重跑，也未据此宣称全场景性能回归通过。未测试实体手机帧率或重新执行弱网启动测试。

源 API 响应、独立构建、桌面及手机截图保存在忽略的 `artifacts.local/liying/`；源码回归入口为 `src/district/liying.test.ts` 与 `e2e/liying.spec.ts`。
