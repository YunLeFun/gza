# 城市沙盒参考与广州建模路线

调研与实现日期：2026-10-07。

后续地图与影像来源集中维护在[资料索引](map-data-sources.md)；时间天气、游览模式与广州塔中心半径 5 km 范围见[游览说明](district-exploration.md)，扩建和可破坏物品见[待办](roadmap.md#guangzhou-exploration)。

## 本轮玩法优化

街区入口 `/district.html` 增加可选配送循环：打开地图接单 → 沿导航到取件点 → 停车取件 → 送到另一处地标 → 积分结算 → 接下一单。保留不接单的自由探索。

- 园区午餐：麦当劳艺苑路创意园 → TIT 北侧。
- 邻里快递：TIT 园区入口 → 丽园雅庭。
- 滨江咖啡：麦当劳艺苑路创意园 → 广州艺术博物院。
- 琶洲加急：丽园雅庭 → 腾讯广州大厦，沿现有有向路网规划。

订单仅在取送两点路网连通时出现。交接要求距停靠点不超过 9 m、速度不超过 1.2 m/s，连续停留 1.25 秒；追逐或拦停期间不能交接。取件前无倒计时，取件后按照路网距离计算建议时间；超时仍可完成并获得基础分。准时最多加 120 分，携带包裹期间没有撞击再加 75 分。

地图和暂停冻结任务；入塔参观期间不能交接，已取件订单仍计时。另选导航地点、取消导航或从通勤/广州塔起点重新出发会结束当前订单。完成单数、累计积分和各订单最佳分保存在本机 `dayun-kicker.deliveries.v1`；正在配送的订单不会跨刷新恢复。这些分数不接入云币或服务端排行榜。

骑行表现增加平滑的速度/加速视野变化、加减速俯仰、一次碰撞的短暂回弹与既有音效。镜头视野最多增加 7°，不改变物理、限速、转向与人物比例。`prefers-reduced-motion: reduce` 关闭新增镜头动态和取送箭头浮动。取送标记复用两个网格与一个材质，180 m 外不绘制，无额外灯光和资源请求。

接单板、地图、当前位置、声音设置和塔内面板按需加载；塔内场景在首次入塔时创建并复用。首页购买确认框也改为打开时加载，以控制两个入口的启动体积。

## 广州是否有现成三维地图

有很接近的公开社区项目：[广州 · 三维实景城市](https://github.com/Tsdsj/guangzhou-3d)，[在线浏览](https://tsdsj.github.io/guangzhou-3d/)。仓库说明其通过 OpenStreetMap 路网/建筑轮廓和公开 DEM 生成广州中心城区，并程序化补齐立面、屋顶设备、骑楼、树木和地标。它包含广州塔、东西塔、广州大剧院、海心桥、广交会展馆等，可以直接作为场景对照和建模方案参考。

其 [LICENSE](https://github.com/Tsdsj/guangzhou-3d/blob/main/LICENSE) 将源代码的 MIT 许可与 ODbL 地图数据、高程数据及第三方库分别列出。仓库也明确说明未标注楼高使用推断、立面并非实景照片、填充建筑不代表每栋实际建筑。它是城市浏览器场景，不能把下载整个项目等同于获得精确、低面数、带游戏碰撞的广州资产包。其 README 中的性能数值是作者设备上的测量，本轮未在我们的手机预算下复测该场景。

官方也有广州 CIM 三维数字底图：[广州市政务服务和数据管理局介绍](https://zsj.gz.gov.cn/zwgk/zfxxgkml/zfxxgkml/qt/rddbjyhzxta/content/post_8524533.html)、[2024 广州 CIM 白皮书](https://zfcj.gz.gov.cn/sjb/bmwj/content/post_9783013.html)。这些材料证明数据和平台存在；本轮未找到可直接下载并复用到公开游戏的完整模型包或开放许可。

## 采用混合建模

继续使用同一米制投影下的公开地图作为位置、路口连接、建筑边界、水域和碰撞的数据底座。导航提供路线与地点校对，无法提供建筑立面、精确楼高或室内模型。

1. 普通街区：由 OSM 轮廓和已知楼高生成建筑；缺失字段保留估计身份，不伪称实测。
2. 街道外观：参考广州社区项目的首层店面、屋顶设备和建筑风格分组；按现有区域合批与距离等级生成，避免逐栋手工搭建。
3. 重点地标：广州塔、腾讯、欢聚、博物院、丽园和 TIT 继续参考公开照片、建筑资料和用户观察单独精修，保持当前已确认的比例、位置与可骑行通路。
4. 第三方成品：只有具体模型的授权、尺度、坐标和可导出格式都明确后，再选择性转换为 GLB，并生成简化碰撞和远景版本。

本轮没有替换地理数据或重建广州场景。这样可先落地玩法改进，同时把更好的广州建筑参考接入后续精修流程。新增功能仍按原有 270 KiB 入口 JavaScript、300 次绘制、90,000 三角形和手机弱网 15 秒的门槛验证。

## 本轮验证

- 全量单元测试：81 个文件、415 项通过；其中新增配送与镜头反馈 7 项，街区测试合计 107 项。
- 类型检查、生产构建、发布资源校验通过；验证快照首页 269.8 KiB、街区入口 269.7 KiB gzip，均小于原 270 KiB 门槛。全产物约 11.14 MiB，未引入外部城市资产。
- 浏览器配送验证覆盖停车取件与送达、地图/暂停冻结、完成仅结算一次、刷新后本机纪录、320 px 触屏取消订单、减少动态效果，以及四条路线在真实 Rapier 世界中逐段通行。
- 配送与广州塔浏览器回归共 6 项通过，确认首次入塔、各观景层、电梯暂停/继续、返回原停车位和手机横竖屏操作正常。
- Fast 3G、4 倍 CPU 降速、冷缓存下，街区首次可操作帧 12.714 秒，低于 15 秒门槛；首页开始竞速的首次帧 10.335 秒。此项为桌面 Chrome 的设备仿真，未代替真机测试。
- 桌面与手机截图经过人工检查；配送目标使用既有导航区域，中央道路视野与触屏操作保持可用。
