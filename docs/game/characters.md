# 人物与载具

GZA 的第一版从电驴骑手与街边生活开始。现有玩法资料以已经出现的对白、外观和交互为准；下方 Demo 人物设定属于后续剧情规划，不表示新的开场与角色已经接入游戏。

## Steam Demo 人物设定（规划） {#demo-cast}

记录日期：2026-10-17。人物信息以维护者本轮设定为准；建议与未定项单独标注。Demo 继续按“两名可操作主角 + 阿榕作为重要 NPC”的范围推进，女主角的叙事地位与是否开放操控分别管理。整体结构见 [Steam Demo v0.1 计划](../steam-demo-v0.1.md)。

### 已明确的人物信息

| 人物 | 身份与背景 | 开场 / 故事位置 |
| --- | --- | --- |
| 大云 | 34 岁，失业程序员 | 开头由玩家操控；从失业到陈叔处注册外卖员，开始配送与故事，随行动逐渐揭露过去 |
| 第二主角，姓名待定 | 22 岁，大学刚毕业；与家人闹矛盾，背井离乡来到广州打工 | 第二名可操作主角；具体工作、专业、家庭矛盾与相遇事件待定 |
| 阿榕 | 女性，广州本地人，摄影师；父亲是摩托车修理师傅，已经失踪 | 女主角；参与送外卖、体验街坊人情；是否将寻找父亲作为配送的直接动机仍是待定方向 |

阿榕的年龄、父亲失踪的时间 / 原因 / 去向，以及青年破界能力的来由尚未确定。三人的职业和处境不直接推导超自然能力。

### 创作建议：让三个人各有要解决的生活问题

以下为参谋建议，尚未作为确定世界观或角色事实。

- **大云：重新获得生活的掌控感。** 给他一个具体的近期压力，例如下一期房租或向家人解释失业，先选择其中一项。用手机消息、旧工牌、登记职业时的停顿逐步表达过去。程序员经验可体现在核对时间、坐标和重复订单、整理异常规律；能力先通过玩家操作体现，解读空间信号作为后续延伸。
- **第二主角：证明自己能独立生活。** 为家庭矛盾确定一件具体的事，例如家里安排的工作与他自己的选择冲突。可表现为给家人报喜、遇到困难硬撑，同时让他有一项已在生活中建立的小本领。具体本领与专业 / 工作一起定；终幕破界须在前文有可感知的反应和代价。
- **阿榕：用自己的方式理解街坊和父亲。** 摄影专题可以解释她为何愿意沿配送路线接触人：同一粥店、修车摊和老街坊既是拍摄对象，也可能认识父亲。发现与父亲有关的线索后，她主动调整调查路线、提出判断，并在关键时刻做出选择。寻父是否从一开始就是配送目的，保留两种动机空间，待第一切片定稿。

建议将人物的共同主题放在“如何在广州重新找到位置”上：大云经历职业中断，青年尝试脱离家庭安排，阿榕重新认识熟悉的城市与父亲。相处中的分歧应来自各自眼前的目标；无需把失业、离家和失踪全部归为同一场阴谋。

### 人物关系与可玩表达建议

- **大云与青年互相补足。** 大云愿意多核对一步，青年更愿意先行动；各自也会误判。用一次共同交付或脱困，让两人都帮到对方，建立切换角色的理由。
- **阿榕同时影响路线和判断。** 她认识街坊、能从照片与地标发现变化，也可能因急于找到父亲而偏向某种解释；她提出的路线与选择实际改变事件，即使 Demo 中不直接操控也保有行动能力。
- **陈叔承担三人相识的日常连接。** 骑手站、取餐点或一次共同订单提供自然交集。陈叔可知道一些街坊往事，关键信息仍需要三人亲自行动取得。
- **父亲的手艺留下可识别的生活痕迹。** 旧工单、工具整理习惯、修补记号或被修好的老车，可选一两项反复出现。先让玩家理解这些普通细节，再在异常世界中看到不合时宜的对应物；父亲是否涉入世界异常继续留白。
- **摄影服务发现与叙事。** 先使用剧情照片、固定拍摄点和前后对照。由玩家观察照片中的店招、门牌或物件变化；自由摄影评分、图像识别和完整相机系统后续另评估，控制 Demo 制作量。

### 一段相遇的候选场景

大云登记后送第一单，在陌生门牌前停下核对地址；青年也为同一处取送 / 工作事务着急，两人先有一次小摩擦。阿榕认出门口的旧称，帮他们把事情办成，同时拍下街景。后续异常订单再次指向这一地点，照片里出现与现场不一致的门牌或父亲修补过的物件。

这一场景仅用于讨论：青年具体工作和三人正式相遇事件尚未确定。第一单先建立可信的日常体验，异常线索再改变玩家对同一地点的理解。

### 下一轮需要明确

- 大云失业多久、眼前最迫切的生活目标，以及本地居住经历；过去信息分几次通过哪些行动揭露。
- 青年的姓名、毕业专业、来广州的时间、当前工作，以及与家人冲突的一件具体事情。
- 阿榕的年龄、摄影主题、配送的直接原因，以及父亲失踪多久；她是否已主动寻人。
- 三人第一次共同完成什么事，角色切换解决什么问题，阿榕在哪一次选择中改变局势。
- 父亲线索最早出现的普通物件，以及 Demo 结尾确认哪一个事实、仍保留什么疑问。

这些设计问题归入 [开发待办 B0-03](../development-backlog.md#baseline-scope) 和 D2-01；本页不复制执行勾选状态。

## 大云：你的骑手角色

陈叔在骑手站对白中称玩家为「大云」。你从电动车上的第一视角骑行，在街区接单、导航、步行、看风景，也能切换到独立的竞速与踢击挑战。

骑手登记、完成配送、获得外观和继续探索，共同构成你在这座城市中的进度。

骑手外观与电动车涂装可以一起变化，比赛和自由骑行共用已装备套装。合作候场也支持设置本人的显示名称和衣服颜色。

## 外卖箱与背包

街区的大云携带黄色保温外卖箱。点击顶部「外卖箱」或按 **B**，即可在地图的外卖箱分类中管理默认 10 格背包；打开时探索与配送计时暂停，Esc / B 关闭并恢复焦点。比赛与合作模式暂不接入背包规则。

初始随身物品为 2 瓶饮用水、1 块备用电池和 1 本骑手手册。饮用水每格最多 5 瓶，使用一瓶恢复 40 点踢击体力；备用电池每格最多 3 块，使用后重置电动车加速冷却。体力充足、加速尚未结束或未骑电动车时，对应补给不会消耗。普通物品可逐件丢弃，丢弃不会返还积分。

到客村骑手站停稳后，打开外卖箱可购买饮用水（15 分）与备用电池（40 分），优先补入同类堆叠。补给与 7 号店改装共用本机积分余额，购买不会降低配送累计得分。背包及补给消费随街区自动 / 手动存档保存，没有背包的旧存档首次恢复时补齐初始物品；已有 8 格背包的存档自动增加 2 个空格，保留物品、补给消费及配送进度。

配送餐品与包裹在取件后自动占用一格，送达或取消订单后自动移除。订单物品不能使用、丢弃或出售；箱子满时不能接单 / 取件，可先消耗或丢弃随身物品腾出一格。订单与背包一起恢复，读档不会额外复制餐品。

## 陈叔：客村骑手站

陈叔在客村帮街坊张罗配送，骑手站位于 TIT 一带。停稳后可以与他交谈，办理骑手登记、聊聊客村，或接一单「园区午餐」。

这单任务先去麦当劳取餐，再送到 TIT 园区北侧。已有订单时，需要先完成或结束当前配送，再接新单。陈叔会提醒你认路、稳稳骑，不急着赶时间。

陈叔的对白由选项推进，登记和接单直接连接骑手与配送进度。首单练熟操作后，他先安排给阿婆送热粥，再接滨江咖啡；大云在送餐途中遇见感染者，回站得知阿婆又来了一单。

陈叔是陈家祠的话事人，这层身份通过行动逐步显露：医院愿意留箱，熟识的街坊接应阿婆，米铺留粮、修车铺借工具，师傅最后提起「陈先生」。他托大云用外卖保温箱秘密运送解药：省二医取箱，沿中山路到陈氏书院南门交接，暗号「粥还热」。解药送达后，大云可在南门通过对讲机联系他，继续给据点送粮米和工具。这个人物身份、疫情和接应点属于游戏的虚构设定。

## 阿婆：同一个门口的两单

第一单是送到丽园雅庭的热粥，阿婆叮嘱「到了轻敲门」。街角异变后，她在同一个地址下了第二单，备注改成「别按门铃，楼道里有人」。大云带回应急包，在感染者附近停稳交接，陈叔安排街坊从后门接应她。

解药送到陈家祠后，救助过的阿婆会出现在接应点。粮米送达后，她惦记着先让跑腿的骑手喝一碗热粥。

## 电动车：城市探索的主角

电动车支持加速、刹车、倒车、掉头、环顾和后视镜。停稳后可以下车步行，电动车留在停车处；回来需要靠近载具才能上车。

头盔佩戴和号牌清晰状态属于街区安全装备。路口检查会查看这两项，收到问题提示后可以整改；装备状态随街区存档保存。普通骑行、踢击与改装操作见[玩家操作说明](/guide/controls)。

### 双座合作电动车

僵尸突围中可以寻找双座电动车，一人驾驶、一人守后座，双方保留各自角色外观。上车、共乘与停车下车都属于同一对局操作；需要交换座位时先下车再上车，个人生命和弹药不会重置。

这属于合作模式，正式线上合作仍待发布验收，开放边界见[玩法设定](/game/modes#僵尸突围)。

### PANZER 彩蛋载具

街区还包含 PANZER 坦克彩蛋。户外探索时，在地图中的「彩蛋代码」输入 `PANZER` 并激活。它在开阔的落点降落后，可以靠近上车、驾驶与开火。

## 车辆建模图鉴

街边还可以看到小汽车、面包车、公交与接驳车，比赛车流包含厢式货车、罐车、洒水车、环卫车及工程车辆。Godot 版城市里还有会看红绿灯的环境车流，以及可以扫码骑行的「云骑」共享单车。各类外形、配色与当前用途见[车辆建模图鉴](/vehicle-models)。

## 街区里的其他角色

路边行人会短距离步行、停步和转身，构成客村、滨江与琶洲的街景。目前这些普通行人没有个人传记或可交谈剧情。

交警与巡逻角色负责电动车检查及追逐流程，活动由本地游戏规则触发。角色与点位都是游戏场景表达。

僵尸突围中有普通僵尸和跑动僵尸，步行、骑行与双座共乘沿用同一份城市战斗规则。
