# 玩法设定

GZA 把**可以随时继续的城市探索**和**目标清楚的短局街机挑战**放在一起。街区的重点是地点、路线与个人进度；比赛的重点是速度、时机和一次次刷新纪录。

## 城市探索

### 自由骑行与步行

从 TIT 出发，在已开放的广州路网内选择目的地，沿导航路线探索。电动车可以停放，上下车后切换骑行与步行；遇到无法继续的位置，可以从暂停菜单「回到路面」。

自由骑行没有统一的完赛终点。你可以继续接单、拜访地点、调整外观，也可以保留当前位置，下次接着探索。

### 城市通勤

城市通勤从丽园雅庭出发，使用广州街区的道路与导航前往通勤目的地。它属于城市骑行流程，与云港环线的封闭赛程不同。

### 外卖配送与骑手进度

配送围绕「接单 → 取餐 → 导航 → 送达 → 结算」展开。抵达交接地点并停车后推进任务，路线、时间和碰撞表现影响本单成绩。

登记成为骑手后完成的订单会累计到制服解锁进度。配送累计得分还与街区门店的改装积分关联，套装、涂装与头盔提供不同的外观选择；相关角色与套装见[人物与载具](/game/characters)。

当前只有一套明确的陈叔对白与园区午餐接单流程，更多人物、多条剧情支线和完整长篇主线尚待扩展。

### 城市游览与广州塔

城市游览使用独立观景镜头，可选择地标、环顾和调整高度。游览期间保留原来的骑行与任务状态，返回后从原处继续。

广州塔提供入塔、楼层、电梯与观景等交互，使用屏幕提示选择目标。它是为游戏制作的室内体验，不代表完整实测建筑。

### 检查与巡逻

街区检查点会示意电动车靠边停车，查看头盔与号牌状态。有问题时按提示整改再放行；已有装备问题而拒绝停车，可能衔接追逐流程，超速也可能触发巡逻。

检查或追逐期间，一些骑行、交接和活动切换会受限制。先处理当前流程，再继续任务。

## 街机比赛

首页只选择剧情或自由模式。比赛统一收进街区 TIT 北侧的「街头赛事」，以下玩法作为赛事规则与目标，不再各占一个城市入口。日常骑行与练习可直接在自由模式进行。

### 经典骑行

在车流中加速、变道并靠近目标，找准时机左右踢击。成功命中会产生夸张的撞飞、声音与画面反馈，连击、速度和行驶表现共同影响得分。

高速正面冲撞也能撞飞车辆，但会损失速度、影响无碰撞表现，而且不会代替踢击命中计入连踹挑战。经典直路的路线选择提供更冒险和更稳妥的节奏。

经典骑行下包含几种短局目标：

| 玩法 | 当前规则与重点 |
| --- | --- |
| 得分挑战 | 90 秒一局，练习车流、速度与踢击，挑战得分 |
| 节奏骑行 | 90 秒一局，踢击时机与节拍配合，获得节奏判定与连段反馈 |
| 极速冲线 / 冲刺挑战 | 75 秒内抵达 1,500 m 目标，越早完成奖励越高 |
| 连踹挑战 / 踢击挑战 | 45 秒内完成 8 次踢击命中，强调目标选择与连击 |

### 计时竞速

计时竞速使用云港环线或随机赛道，按顺序经过检查点并完成赛程。云港固定环线为两圈；随机赛道由地图种子决定布局，可以反复挑战同一张地图。

弯中转向并刹车 / 使用手刹可以积累漂移能量，保持走线后松开释放短时加速。漏过检查点、反向通过或没有完成全程，都不会产生有效的完赛纪录。

### 道具赛

道具赛在同一类赛道上加入问号盒。一次持有一个道具，使用后再拾取下一件；氮气负责短时冲刺，护盾保护一次碰撞，巨大化与迷你化改变踢击和操控体验。

当前道具赛属于单人试跑。

## 记录与探索进度

各比赛保存自己的最佳得分或有效完赛时间，计时竞速与道具赛的纪录分别管理。

街区保存位置、配送、骑手登记、故事、载具、塔内和游览等探索状态，提供自动槽与三个手动槽。街区快照不保存比赛中途状态；同一人物切换玩法，不意味着所有对局都能中途续跑。

网页版进度保存在当前浏览器，客户端保存在本机文件。云乐坊登录不等于街区存档跨设备同步；操作与恢复方式见[存档与读档](/guide/saves)。

## 僵尸突围

「僵尸突围」是广州地图中的 1–4 人合作活动。步行、驾驶、后座共乘和下车战斗都是本局操作，不需要选择另一种玩法或更换房间。玩家可以寻找停放的电动车，靠近后上车；每辆最多两人，一人驾驶、另一人共乘，停车后可下车继续战斗。

每人保留独立生命与弹药，使用枪械、近战工具和救援清除三波僵尸。倒地后由附近队友救援，全员倒地会失败，单人倒地直接结束；上下车不恢复生命或弹药。街区内可以直接开始本地单人挑战，无需建房或准备，结束后恢复探索位置与状态。

开局后不接收新玩家，不支持断线续局或房主迁移。好友房菜单只释放本人的输入，其他成员继续战斗；本地单人在菜单或后台暂停。旧两人固定路线配送房仅保留为旧邀请和云端房的兼容路径，不再作为独立主玩法。

::: info 正式开放边界
本地僵尸突围可离线游玩，首次网页加载仍需取得应用与地图资源。统一城市规则与好友大厅已接入，生产多人服务与真实 Steam 联机仍以实际开放和验收状态为准；旧云端固定路线房不会自动迁移为新城市房。本轮工作不表示官网已部署。

Steam 好友竞速、Cloud 与创意工坊等入口不能视为当前已经上线的服务。下载与平台状态见[下载与安装](/guide/installation)。
:::

## 从街区开始活动

地图中的活动列表与蓝色标记连接上述玩法。选择导航，抵达地点并停车，再按界面提示开始。比赛会先展示模式和赛道，由你确认后开局；菜单与结算提供「返回街区」，回到活动出发地点。

配送中、被拦停或追逐时，以及塔内、地铁内或上层位置，不能直接跨模式开始活动。当前活动地点见[玩家活动指南](/guide/gameplay)。

后续内容会优先把现有城市系统连接成完整的任务体验，再增加任务差异、人物与店铺，最后逐区扩大城市。具体新玩法和正式开放时间以实际发布说明为准。
