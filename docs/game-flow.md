# 游戏主模式与活动流程

游戏以「剧情模式」与「自由模式」为两个主入口，参考 GTA 的城市任务与自由活动结构。两者复用同一份广州地图、车辆、角色、交互、任务、奖励和存档；模式决定引导方式，不另建城市场景。竞速、配送、观景与僵尸是城市活动，好友合作沿用对应活动的联机同步。

| 主模式 | 当前体验 |
| --- | --- |
| 剧情模式 | `/district.html?mode=story`；沿陈叔的客村骑手故事登记、接单并完成配送。欢迎页和暂停 / 地图导航显示当前任务引导，启动时没有已有导航目标则前往骑手站；已有任务、位置和对白进度继续保留。首期内容为陈叔对白与骑手配送，后续章节尚未实现。 |
| 自由模式 | `/district.html`；玩家自行选择骑行、步行、游览、地铁、改装、接单、竞速和僵尸突围。剧情人物仍可交谈，任务与奖励使用同一份规则。 |

欢迎页、暂停菜单与地图导航可切换主模式，保留当前画布、人物位置、车辆、订单与骑手档案。切换只更新引导与当前 URL，不取消任务、不重新发奖。比赛和合作活动带回原主模式；原有未指定模式的入口与存档继续按自由模式运行。故事运行时仍在与 NPC 交谈时按需加载。

主菜单的「新手教程」进入街区操作引导。玩家依次完成加速与转向、刹车、踢击或加速道具、打开地图、选择活动导航。教程由实际操作推进，可跳过，并在街区欢迎页和暂停菜单重玩；完成记录使用 `dayun-kicker.district-tutorial.v1`。直接进入街区仍可自由探索。

## 街区活动入口

地图的「街区活动」与蓝色地图 / 世界标记使用同一份活动目录。点击导航规划真实街区路线，抵达对应地点并停车后开始活动。上层、塔内、地铁、正在配送、被拦停或追逐时不能跨模式开始活动；剧情和门店沿用原有更近的交互范围。

| 地点 | 活动 |
| --- | --- |
| TIT 园区入口 / 客村骑手站 | 自由骑行、陈叔的骑手故事 |
| 丽园雅庭 | 城市通勤 |
| 麦当劳 · 艺苑路创意园 | 外卖配送 |
| 广州艺术博物院 | 城市游览 |
| 7 号电动车 · 新港中路店 | 车库与装备 |
| TIT 北侧 | 街头赛事（计时、道具与得分规则） |
| 海心桥南岸 | 僵尸突围 |

首页的「开始游戏」进入剧情模式，也可直接选择自由模式；不再展示赛车模式或赛道配置。街区仅保留 TIT 北侧的「街头赛事」入口，将计时、道具、得分、冲刺、踢击与节奏挑战收为同一赛事的规则。抵达入口后展示赛事规则和赛道，玩家确认「开始比赛」后开局。切换前保存街区位置、车辆和进度；比赛主菜单、暂停和结算、合作大厅、暂停和结算提供「返回街区」，恢复活动出发地点。合作返回会先退出房间。无法保存时留在街区提示恢复存档，避免丢失返回位置。随机赛道收在赛事准备页；联机竞速、账号、排行榜和装备入口仍可从首页访问。原有 `classic`、`time`、`items`、`sprint`、`kick-rush`、`music` 活动链接继续识别原规则与独立纪录，但不再生成多个街区入口。

## 僵尸突围 {#城市僵尸挑战}

「僵尸突围」是自由探索内的可选机制，入口位于欢迎页、暂停菜单和地图的城市游览分类。直接在当前城市开始，无需单人建房或准备，复用已加载的城市场景与画布。挑战暂停原来的探索模拟，退出后恢复原位置和进度；从首页进入同样走街区入口。邀请好友进入 `/coop.html` 统一组队大厅，离开前退出房间并返回街区。

城市合作、驾驶和双座共乘是同一局里的操作。1–4 人可以步行打僵尸、寻找双座电动车、上车驾驶或共乘，并在停车后下车继续战斗；个人生命、弹药和波次沿用同一权威状态。旧固定路线房仅通过 `/coop-legacy.html` 兼容旧邀请与旧云端连接，不作为单独主玩法。生产云端与真实 Steam 的开放状态见[僵尸突围](city-zombie-coop.md)。

## 旧双座路线的生活物品武器 {#双人突围的生活物品武器}

以下为旧固定路线兼容房的武器记录，不代表统一城市突围已加入这些物品。旧后座保留冲锋枪和霰弹枪，并增加三种具有不同攻击规则的物品：

| 物品 | 攻击 | 资源 |
| --- | --- | --- |
| 鸡毛掸子 | 3.2 m 内向前扇形挥击；墙体阻挡 | 不消耗弹药，挥击有冷却 |
| 煤气罐 | 朝瞄准方向投掷，在命中点产生 4 m 范围冲击；障碍挡住冲击 | 每次 1 罐，初始另有 5 罐，补装后再投 |
| 弹弓 | 45 m 内精准单发石子 | 每次 1 颗，初始另有 60 颗，补装后再射 |

数字键 1–5 直接选择；E、手柄 Y 或触屏「换武器」循环。攻击仍使用鼠标左键 / Space、手柄 RT 或触屏攻击按钮；R / 手柄 X / 触屏补装对应物品资源。HUD、模型、声音和特效随物品切换，伤害、冷却、补给与资源由合作房间的权威规则判定，切换不会补满资源。

活动目录维护于 `src/game/gameFlow.ts`，街区地点与到达条件维护于 `src/district/activities.ts`；武器规则维护于 `packages/dayun-kicker-coop/src/map.ts` 和 `rules.ts`。
