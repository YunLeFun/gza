# 街头街机 UI

主视觉来自街机海报和城市路牌：斜切的深蓝背景、巨幅中文重字、纸白路线菜单、橙色启动踏板。游戏道路仍是背景，界面不用新的图片、字体下载或 WebGL 场景。

## 设计系统

- 沥青黑 `#142028`：正文、描边、硬阴影。
- 交互蓝 `#2F60D3`：选中路线、进度、焦点。
- 背景蓝 `#2C4B87`：品牌主面，以 94% 不透明度叠在道路上。
- 路牌白 `#F0F4EE`：菜单底色、标题。
- 信号橙 `#F0784D`：启动、踢击。
- 安全黄 `#F2C852`：时段选中、倒计时。
- 薄荷绿 `#88CBB2`：稳定状态。

展示字使用本地中文黑体的最重字重，双行大字配轻微倾斜。正文使用系统无衬线，数字使用已有等宽数字字体。视觉层级：品牌 → 启动 → 路线 → 时段与导航 → 记录。界面沿清晰的左边界对齐，圆角控制在 0–6px；只为触屏踏板保留明显弧角。

```text
桌面                              手机
╱ 深蓝面        实时道路           巨幅双行品牌
  暴力          ┌ 准备出发 ───┐    简短标语 / 三个时段
    电驴        │ 六项导航     │    ┌ 六项导航 ───┐
  标语          │ 四条路线     │    │ 四条路线     │
  昼 / 暮 / 夜  │ 最佳记录     │    │ 最佳记录     │
                └ 橙色启动 ───┘    └ 橙色启动 ───┘
```

短屏改成紧凑双列路线，确保启动按钮完整留在首屏。行驶中减少主视觉面积，使用纸白计分牌、醒目倒计时和橙色踢击踏板，给道路中央留出视野。

## 实现边界

StartOverlay 负责布局和菜单状态；LaunchBrand 只展示字标；ReadyStartPanel 负责模式选择和启动事件；SceneSwitcher 负责时段；ReadyMenuTabs 保留键盘导航；StatusHud 显示实时状态。触屏输入、运行时加载、账户和场景逻辑保持现有组件契约，通过 props 和 emits 传递。

### 内容面板统一

沿用以上配色与字阶，五个辅助 tab 也使用纸白内容区、沥青正文和交互蓝选中态。左对齐标题和说明，橙色只用于主要操作。清理原有深色嵌套卡片；内部内容通过同一个区域纵向滚动，不再在车库中嵌套横向轮播、在排行中嵌套第二层滚动。

```text
联机                帮助              排行             关于             车库
标题 / 简短说明      三种操作提示       标题 / 模式       游戏 / 作者       账号 / 登录
房间号 / 玩家状态    键鼠与触屏说明     排名 姓名 分数    简介              涂装 名称 装备
创建 / 加入          完整帮助入口       刷新 / 空状态     三个外部链接      纵向皮肤列表
```

组件边界：OnlineRacePanel 管理房间输入并发出既有 create/join/leave/login；ReadyHelpPanel 展示快捷操作并发出 openHelp；LeaderboardPanel 展示列表并保留 refresh/setOpen；AboutLinks 展示项目说明和链接；AccountPanel 管理账号展示并透传皮肤事件；SkinShop 展示涂装列表并发出 equip/unlock。StartOverlay 只组合这些面板。各组件拥有自己的布局 CSS，共用菜单按钮、标题与说明的基础样式。

自检：只换导航颜色会留下两套视觉语言，因此这次连标题、输入、列表、空状态和按钮一起替换；车库保留涂装色块这一与游戏有关的识别元素，排行榜按实际名次展示数字，避免附加无意义的装饰编号。

皮肤列表进一步减少线条：移除每行底部分隔线和色块描边，用 6px 行间留白分隔；内容左右留出 12px，标题与列表间隔 14px。选中行保留浅蓝底和居中的短蓝条，操作按钮保留轮廓，便于识别可点击区域。布局仍由 SkinShop 独立负责，沿用既有配色、字号和事件。

### 色彩精修

背景蓝与交互蓝分开：大面积背景降低饱和度和亮度，选中与焦点仍清晰。桌面斜切边界从 49% 收到 44%，手机从 48% 收到 42%，短屏横向从 43% 收到 40%；道路侧遮罩也略减弱，露出更多场景。橙、黄小幅降饱和度，保留启动、踢击与倒计时的辨识度。皮肤涂装的实际颜色保持其数据定义，提示底色则从共享色彩变量混合生成。标题、布局尺寸与按钮触摸范围保持原有设计。

本轮应用类型检查与生产构建、性能预算和发布产物检查通过；四种尺寸的首屏检查与 390px 下五个内容页检查共 5 项通过。新配色的纸白 / 交互蓝对比度为 5.06:1，沥青黑 / 橙色为 5.92:1，沥青黑 / 黄色为 10.39:1。桌面、手机的三个时段及手机行驶界面另保存构建预览截图于 `artifacts.local/color-refinement/`，两种尺寸未发现页面脚本错误。此轮仅修改 CSS 和设计说明，未新增资源或渲染效果，也未进行真实手机实测。

## 设计自检

避免把旧版深色圆角卡片仅换色：品牌使用显著不同的尺度，模式用连续路线列表，主操作采用硬边踏板。装饰集中在品牌和背景斜切，菜单不堆叠徽章、编号或循环动画。辅助业务面板保持足够对比，动效服从 reduced-motion 设置。
