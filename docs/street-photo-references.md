# 广州街景参考与素材边界

项目使用经提供者许可查看的自行拍摄街景作为建模参考。原片、私人图库入口、设备与同步设置、精确拍摄时间、拍摄者位置、原始文件标识及授权凭据保存在仓库外。公开文档使用稳定的参考编号，记录地点、可观察细节、模型对应关系与误差边界。

## 来源与使用

| 参考编号 | 建模用途 | 对应记录 |
| --- | --- | --- |
| `street-liyuan-night` | 丽园雅庭连廊、活动空间、驿站、院门、停车区与树木 | [夜间建模参考](liyuan-night-reference.md) |
| `street-chigang-hospital` | 赤岗路口向医院方向的体量与远景关系 | [医院参考](guangdong-second-hospital.md) |
| `street-tencent-dusk` | 腾讯西侧路口设施、云带与黄昏色调 | [路口与晚霞参考](tencent-junction-dusk.md) |
| `street-tencent-entrance` | 腾讯入口植栽、座椅、栏杆灯带与对街雨篷 | [入口参考](tencent-entrance-reference.md) |

这些照片仅用于观察参考，未作为照片贴图或原片随游戏分发。许可查看不能直接推定为允许公开原片、再分发或商业使用；需要分发时，应先取得相应授权，并检查可识别的人物、车牌和私人信息。

## 私下保管与公开记录

原片与参考编号的对应、提供者、拍摄日期、原始文件名、校验值和授权范围由维护者在仓库外保管。需要向工具提供原片时，仅导出本次使用的文件到被忽略的 `artifacts.local/street-photos/`；不要复制整个图库、建立图库软链接或把原片附到公开 Issue / PR。

每次公开模型记录应包含参考编号、地点与观察方向、用于还原的细节、估计尺寸、对应源码和验证结果。游戏位置优先使用可追溯的公开地图数据；照片定位不能当作测绘精度。需要发布的新媒体仍按 [COS 资源流程](media-assets.md)管理，并另行确认素材许可。
