# 下载与安装

可以直接打开[网页版游戏](https://dayun-kicker.yunle.fun/)游玩。客户端将单人竞速和街区资源保存在本机，安装后支持离线游玩。

也可以查看官网的[客户端下载页](https://dayun-kicker.yunle.fun/download.html)。该入口暂未开放时，请使用本页上方的下载链接。

## macOS 安装

1. 确认设备使用 Apple 芯片。可以从苹果菜单的「关于本机」查看芯片信息；当前 arm64 包面向这类 Mac。
2. 下载 ZIP 并解压，得到游戏 App。新构建使用完整名称 `GZA：暴力电驴.app`；2026-10-09 已发布的预览包仍为 `GZA.app`。
3. 将应用移入「应用程序」文件夹，再打开。
4. 首次启动按系统提示确认从互联网下载的应用。若提示文件损坏或无法验证，请重新从官方下载，并核对下载页显示的 SHA-256；不要关闭系统安全保护。

如果仍无法启动，请在反馈中附上系统版本、芯片型号和错误提示文字。当前还没有公开 Intel Mac 客户端，Intel 设备可以先使用网页版。

## 离线与联网功能

| 功能 | 网页版 | 当前客户端预览版 |
| --- | --- | --- |
| 单人竞速与广州街区 | 打开游戏时需要网络 | 安装后支持离线 |
| 本地存档 | 当前浏览器的本地存储 | 本机文件 |
| 云乐坊账号、商店与付费权益 | 需要网络与对应在线服务 | 尚未接入网页登录与权益 |
| 正式合作房间 | 尚待线上发布验收 | Steam 合作尚未正式开放 |

当前两种版本共用主要玩法，Web 的地图与玩法范围尚未做正式试玩裁剪。之后若推出客户端专属内容，会在手册与版本说明中明确标注。

## 更新客户端

当前预览包不提供自动更新。新版本公开后重新下载，关闭旧应用再替换应用文件。存档保存在独立的本机数据目录中；更新前可从「设置 → 通用 → 打开存档目录」备份。

新旧版本的存档兼容性以实际提示为准。遇到「版本不受支持」时保留原档，按[存档与读档](/guide/saves)处理。
