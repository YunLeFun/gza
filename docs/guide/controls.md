# 操作说明

比赛与街区有不同的刹车、倒车和踢击规则。游戏内「设置 → 操作」提供键盘与手柄图示；街区暂停菜单中的「操作说明」可以随时重新查看。

## 键盘与鼠标

| 操作 | 比赛骑行 | 街区骑行 |
| --- | --- | --- |
| 加速 / 前进 | W 或 ↑ | W 或 ↑ |
| 向左 / 向右转向 | A / D 或 ← / → | A / D 或 ← / → |
| 刹车 | S 或 ↓；转弯时可用于漂移 | Shift |
| 减速后倒车 | 无此操作 | S 或 ↓；停车后倒车 |
| 左踢 / 右踢 | Q / E | Q / E |
| Space | 朝镜头偏向的一侧踢击 | 智能选择附近目标踢击 |
| 使用道具 | F | Z 使用加速道具 |
| 环顾 | 开始后点击画面，再移动鼠标 | 点击捕获鼠标后环顾；触屏拖动 |
| 暂停 / 继续 | Esc 或 P | Esc 或 P |

桌面街区点击画面一次后，松开鼠标即可持续环顾。按 Esc 释放鼠标并暂停，打开地图或其他菜单也会释放；返回探索后再次点击画面。触屏仍使用拖动环顾，浏览器不允许锁定鼠标时也可以按住拖动。

自由骑行时，鼠标环顾只改变视角；车身和行驶方向保持一致，由 A / D 或左右方向键转向。侧看或回头时，电动车仍沿车头方向前进，W / ↑ 不会改为沿镜头方向行驶。

两个模式中，刹车都优先于油门和加速道具。比赛可以持续刹车至完全停车，松开后恢复巡航或按油门逐渐起步；弯中的手刹漂移使用较轻的制动力。街区按住倒车键会先减速至零，再向后骑行；只想停车时使用 Shift。

### 街区快捷操作

| 操作 | 按键 |
| --- | --- |
| 打开 / 关闭地图 | M |
| 打开 / 关闭外卖箱 | I；也可点击顶部「外卖箱」 |
| 户外步行跳跃 / 奔跑 | Space / 按住 Shift |
| 上下车 | F；上车需要靠近停放的载具 |
| 掉头 | R |
| 切换第一 / 第三人称 | V |
| 切换后视镜 | B |
| 入塔 / 出塔 | G；在可交互位置使用 |
| 交谈、进店或进入地铁站厅 | 按屏幕提示使用 E |
| 选中楼层后乘梯 | Enter 或 Space |

户外步行使用镜头相对 WASD / 方向键移动，A / D 横移，Space 跳跃、Shift 奔跑；手柄 A 跳跃、按住左摇杆奔跑，触屏提供「跳跃」「奔跑」。跳跃期间继续移动，落地后可再次起跳或上车；骑行 A / D 仍为转向。V 视角、F 上下车参考 GTA 风格，探索的加速道具使用 Z，比赛仍使用 F。游览同样支持 WASD / 方向键。靠近门店、陈叔或地铁入口时，E 会用于当前交互，以屏幕提示为准。

车辆或人物卡住时，打开暂停菜单选择「回到路面」。

打开街区大地图后，Mac 触控板双指向外张开放大、向内捏合缩小，缩放以光标位置为中心。也可以按住 Ctrl 滚动鼠标滚轮，或使用地图上的「＋」「−」「全图」按钮；放大后拖动地图查看其他位置。

功能地点优先显示短名称，拥挤区域会自动避让或隐藏部分名称。悬停地点标记或用 Tab 聚焦，可查看完整名称与功能；点击、触屏点按或 Enter / Space 可导航到该地点。

## 标准手柄

下表使用 Xbox 按钮名称；其他采用标准映射的手柄使用相同位置的按钮。连接后按一下手柄按钮，让游戏识别设备。

| 操作 | 按钮 |
| --- | --- |
| 转向 | 左摇杆 |
| 环顾 | 右摇杆 |
| 油门 | RT |
| 刹车 | LT |
| 手刹 | 比赛中 RB，可用于漂移 |
| 左踢 / 右踢 | 按住 A，再点 LB / RB；街区右踢改为 A + 按下右摇杆 |
| 智能踢击 | B |
| 道具 | X；街区为加速道具 |
| 暂停 / 继续 | Menu |
| 街区地图 | View |
| 街区上下车 | RB；与僵尸突围相同 |
| 街区入塔 / 出塔等情境交互 | Y |
| 街区掉头 / 后视镜 | 按下左摇杆 / 右摇杆 |
| 户外第一 / 第三人称 | 方向键上 |
| 塔内选楼层 / 乘梯 | 方向键 / A |

比赛按住 A 踢击时，RB 不会同时触发手刹。街区左摇杆向前加速、后推倒车，LT 独立刹车；RB 专用于上下车，按住 A 再按右摇杆可右踢。步行与游览使用左摇杆移动，上下车后先释放按住的移动输入，再继续移动。

## 触屏

比赛中，按住油门持续加速，在电动车面板上左右拖动转向；使用画面上的刹车、踢击和道具按钮。街区提供左右转向、倒车、刹车和加速按钮，拖动画面环顾；踢击与加速道具在独立按钮区。普通街区和僵尸突围都点「上车／下车」切换，路边停稳的电动车可直接骑走。

可以同时按住油门和转向，再用另一根手指操作刹车或道具。打开菜单或切到后台会释放持续操作，回来后重新按住所需按钮。

## 菜单导航

键盘使用 Tab / Shift + Tab 切换焦点，Enter / Space 激活按钮，Esc 返回或关闭；选项可用左右方向键调整。手柄使用方向键或左摇杆选择，A 确认、B 返回，设置分类可用 LB / RB 切换。

## 僵尸突围操作

步行、驾驶和双座共乘使用同一局。靠近停稳且有空座的电动车上车，司机负责驾驶，第二名玩家进入后座；停车后可以下车继续战斗。切换座位先下车，再重新上车。

| 操作 | 键鼠 | 标准手柄 |
| --- | --- | --- |
| 步行 / 驾驶 | WASD；驾驶时 W/S 前进/倒车，A/D 转向 | 左摇杆 |
| 瞄准 / 环顾 | 点击画面后移动鼠标；无鼠标锁时拖动 | 右摇杆 |
| 上车 / 下车 | X | RB |
| 步行跳跃 | Space | A |
| 步行奔跑 | 按住 Shift | 按住左摇杆 |
| 驾驶急刹 | 按住 Shift | LT |
| 步行 / 后座开火 | 鼠标左键 / J | RT |
| 步行近战 | Q / 鼠标中键 | B |
| 切换近战工具 | Z | LB |
| 换弹 | R | X |
| 切换枪械 | 1 / 2 | Y |
| 步行救援 | 按住 E | 按住 LT |
| 菜单 | Esc | Menu |

司机不能同时开枪，后座不能操纵车辆；车上不能近战或救援，需停车下车后使用。驾驶方向由车身决定，鼠标侧看不会改变 W/S 的行驶方向。

触屏根据座位显示步行、驾驶或枪械控件，靠近车辆时显示「上车」，车上显示「下车」，司机可按住「急刹」。拖动画面瞄准或环顾，操作支持多点触控；取消指针、进入菜单或切到后台会释放持续操作。

本地单人在菜单或后台暂停，好友房只释放本人的输入，其他玩家继续战斗。线上合作开放状态见[玩法与活动](/guide/gameplay#僵尸突围)。

### 旧双座路线兼容操作

旧邀请与旧云端固定路线房使用 `/coop-legacy.html`，保留原驾驶加速 W/S、司机 Space/Q 踢击、后座 Space/鼠标左键攻击、R 补装、1–5 直接选武器、E 循环切换及原手柄映射；不能下车步战。这是历史兼容路径，当前僵尸突围的统一操作以上表为准。

## 僵尸突围旧步战入口 {#城市僵尸合作操作}

原城市步战入口与操作锚点继续有效，现已使用上述统一操作。统一城市房使用 Space／手柄 A 跳跃，Shift／按住左摇杆奔跑，鼠标左键／J／RT 开火，E／LT 救援，X／RB 上下车。

城市僵尸合作仍用 Z 切换近战工具、Q / 鼠标中键近战；Z 加速仅适用于自由探索，不覆盖城市模式。
