# 快速开始

**GZA：暴力电驴**是一款第一视角电动车街机与广州城市探索游戏。GZA 是「广州行动（GuangZhou Action）」的缩写。你可以在街区自由骑行、接配送订单，也可以直接选择竞速和踢击挑战。

## 第一次游玩

1. 打开[网页版游戏](https://dayun-kicker.yunle.fun/)，或启动已经安装的客户端。
2. 在主菜单选择「新手教程」。教程进入广州街区，依次练习加速转向、刹车、踢击或加速道具、打开地图和活动导航。
3. 按画面提示完成实际操作；也可以跳过，之后从街区欢迎页或暂停菜单重新开始。
4. 学会骑行后，在地图中挑选一个「街区活动」，导航到目的地并停车，按提示开始。

键盘、触屏和手柄都有对应操作。尤其留意：**街区的 S / ↓ 是减速后倒车，Shift 才是刹停；比赛的 S / ↓ 是刹车。**完整对应表见[操作说明](/guide/controls)。

## 想先玩什么？

| 想做的事 | 推荐入口 |
| --- | --- |
| 熟悉转向、刹车与地图 | 新手教程 |
| 没有计时压力地逛广州 | 自由骑行 |
| 学会接单、规划路线 | 街区活动中的外卖配送 |
| 挑战个人圈速 | 计时竞速 |
| 尝试加速、护盾与变身 | 道具赛 |
| 练习踹大云汽车 | 经典骑行或踢击挑战 |

玩法目标和街区活动地点见[玩法与活动](/guide/gameplay)。合作模式的线上开放状态也在该页说明。

## 暂停与继续

比赛与街区使用 Esc / P 或手柄 Menu 暂停，触屏可点击暂停按钮。比赛开始后，点击画面可以用鼠标环顾；按 Esc 释放鼠标，方便操作菜单。

街区会自动保存探索进度。再次进入时选择「继续上次探索」，确认后再继续移动；重要进度也可以另存到手动槽位。离开前确认保存状态，具体见[存档与读档](/guide/saves)。

## 调整到舒服的状态

设置里可以调整画面、声音、操作和通用选项。画面不流畅时，先降低渲染分辨率上限或帧率上限；声音和音乐可分别调整。手机建议使用能看清地图与操作按钮的方向游玩。

网页版和客户端目前共用主要玩法。客户端支持单人竞速与街区离线游玩；安装和平台状态见[下载与安装](/guide/installation)。
