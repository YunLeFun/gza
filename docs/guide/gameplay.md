# 玩法与活动

首页选择剧情或自由模式进入广州街区，在城市中接单、探索和参加活动。赛车统一从 TIT 北侧的「街头赛事」入口开始。

## 街头赛事规则

| 玩法 | 目标与规则 |
| --- | --- |
| 得分挑战 | 在车流中骑行与踢击，挑战得分；可选择经典直路或弯道试跑 |
| 计时竞速 | 沿赛道依次经过检查点，完成圈数或终点目标，刷新个人完赛时间 |
| 道具赛 | 经过问号盒拾取道具，利用道具和漂移完成赛程；目前为单人玩法 |
| 冲刺挑战 | 在限时内完成距离目标 |
| 踢击挑战 | 在限时内完成命中目标 |
| 节奏骑行 | 跟随节拍骑行与踢击 |

赛事准备页的得分挑战可选择练习、节奏、极速冲线或连踹目标。开始前查看本局规则、赛道预览与目标；不同赛道的圈数、距离和检查点以当前界面为准。

竞速必须按顺序通过检查点，直接抄近路漏过检查点不会完成有效赛程。有效完赛才会刷新最佳时间，计时竞速和道具赛分别保存纪录。

### 漂移与道具

速度足够时，在弯中转向并刹车 / 使用手刹可积累漂移能量，保持走线后松开释放短时加速。低速、直路、碰撞或驶出道路不能持续获得奖励。

道具赛一次持有一个道具，按 F、手柄 X 或道具按钮使用。库存未使用前，新盒子不会覆盖已有道具。

| 道具 | 效果 |
| --- | --- |
| 氮气 | 短时冲刺加速 |
| 护盾 | 抵挡一次车辆碰撞 |
| 巨大化 | 强化踢击力度和范围，转向稍慢 |
| 迷你化 | 缩小碰撞范围，加快转向与踢击冷却 |

护盾保护车辆碰撞，仍要注意道路边界。道具赛当前没有 AI 名次或多人道具攻击。

## 街区探索

自由骑行从 TIT 园区出发，可以打开广州地图选择目的地，沿导航路线探索广州塔、客村与琶洲等区域。步行、骑行、城市游览和不同地点的交互使用屏幕上的提示。

地图中的「街区活动」和蓝色活动标记对应同一组地点：

| 地点 | 活动 |
| --- | --- |
| TIT 园区入口 / 客村骑手站 | 自由骑行、陈叔的骑手故事 |
| 丽园雅庭 | 城市通勤 |
| 麦当劳 · 艺苑路创意园 | 外卖配送 |
| 广州艺术博物院 | 城市游览 |
| 7 号电动车 · 新港中路店 | 车库与装备 |
| TIT 北侧 | 街头赛事（计时、道具与得分规则） |
| 海心桥南岸 | 僵尸突围，线上合作以实际开放状态为准 |

选择活动导航，抵达指定地点并停车后开始。比赛会先展示模式与赛道，再由你确认开局。比赛菜单和结算中的「返回街区」可以回到活动出发地点。

配送中、被拦停或被追逐时，以及塔内、地铁内或上层位置，不能直接跨模式开始活动。先完成当前流程并回到合适地点，再尝试开始。

### 配送与装备

前往麦当劳接单，按订单提示取件并送达。规划路线、控制时间、避免碰撞可以获得更好的配送表现。

骑手登记后完成配送，可以逐步解锁任务制服；登记前的订单不计入制服任务。主菜单「车库」和街区装备入口可查看解锁条件并装备已获得的外观。

网页版的账号、购买与权益需要在线服务。当前离线客户端尚未接入云乐坊网页登录与付费权益，具体以当前版本显示的可用入口为准。

## 僵尸突围

僵尸突围可以从街区直接单人开始，也支持 1–4 人好友房。玩家在同一局内步行战斗、寻找电动车、上车驾驶或双人共乘，停稳后下车继续射击、近战和救援；不用在“城市合作”与“双座共乘”之间选模式。

可以前往丽园雅庭、丽影广场和7号电动车门店附近找车，三处各安排三个停车位，出生点附近也可能有车。普通街区的路边电动车也能直接骑走：先下车，再靠近另一辆停稳的车，按 X、手柄 RB 或「上车」即可骑行，原车留在原处；停车位置会存档。在僵尸突围中使用同样的上下车操作，还能与队友双人共乘。

每辆电动车最多两人，驾驶员控制行驶，后座可以瞄准射击。每人仍有独立生命和弹药，上下车不会补满状态；倒地后由附近队友救援，单人倒地或全员倒地结束本局。当前目标是清除三波僵尸，离开挑战后恢复原来的探索位置与状态。

旧两人固定路线外卖房只保留旧邀请和旧云端连接兼容，不再作为玩家的独立玩法选择。

::: info 开放状态
本地僵尸突围可离线游玩，首次网页加载仍需取得应用与地图资源。统一好友房规则与入口已接入，生产多人服务和真实 Steam 联机仍以实际开放与验收状态为准。旧云端房不会自动迁移为新城市房，本轮工作也不表示官网已部署。
:::

键鼠、手柄和触屏的操作见[操作说明](/guide/controls#僵尸突围操作)。房间开始后不接收新成员，不支持断线续局或房主迁移。
