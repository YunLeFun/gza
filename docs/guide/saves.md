# 存档与读档

广州街区提供一个自动存档和三个独立手动槽位。存档保存探索状态，方便下次回到原来的位置继续；比赛中的中途状态不在街区存档范围内。

## 自动存档

街区每 5 秒，以及暂停、打开地图、切到后台和正常退出时自动保存。再次进入街区时，欢迎页显示「继续上次探索」，确认后再恢复移动与配送计时。

恢复时车辆会停稳，持续按键与正在生效的加速会释放，避免一进场就撞车。

## 手动保存

1. 在街区暂停菜单选择「存档 / 读档」，或打开地图中的「存档与读档」面板。
2. 查看各槽位的探索方式与保存时间，选择存档 1、2 或 3 的「保存」。
3. 空槽位直接保存；已有内容、损坏内容或其他版本数据需要确认覆盖。
4. 等待界面显示保存成功，尤其是客户端需要确认文件已经写入磁盘。

重要分支前可以使用不同槽位保留几个探索节点。确认覆盖会替换该槽位的旧内容，按「取消」或 Esc 可保留原档。

## 读取存档

在同一面板选择自动槽或手动槽的「读取」，确认后恢复对应状态。读档前会尝试保留当前探索进度；无法安全保存时，界面会提示错误并停止读档。

**读档完成后保持暂停。**关闭地图或存档面板，再按界面提示继续。不要将槽位显示的时间与本次比赛成绩混为一谈。

## 保存哪些内容？

| 会恢复 | 会重新初始化或单独处理 |
| --- | --- |
| 街区位置、朝向、相机、里程与探索时间 | 路过的行人、临时炮弹与建筑破坏 |
| 导航目的地、正在取件或配送的订单与计时 | 导航路线按当前路网重新计算 |
| 配送记录、骑手登记、故事和装备进度 | 付费外观仍需要验证当前账号权益 |
| 步行与停放载具、塔内位置、电梯与游览状态 | 竞速比赛中途状态 |
| 时间、天气与巡逻状态 | 比赛纪录由各玩法单独保存 |

已完成的配送恢复后不会重复结算。如果地图变化导致原位置无法安全放置，游戏会尝试回到可通行路面；不兼容的地图存档会提示无法读取。

## 网页版与客户端

**网页版**保存在当前浏览器、当前游戏站点的本地存储中。其他浏览器、设备和站点地址不会自动共享；清理网站数据会删除本地存档。登录云乐坊不等于街区进度已经跨设备同步。

**客户端**保存到本机文件。可在「设置 → 通用」中点击「打开存档目录」，查看本地存档位置。需要自行备份时，先正常关闭游戏，再复制存档目录；恢复时也应关闭游戏并保留现有文件副本。当前预览版未启用正式 Steam Cloud，不能依赖云同步作为备份。

网页版与客户端目前没有提供互相导入存档的玩家操作入口。

## 保存失败或存档损坏

游戏会保留上一个有效版本作为备份，主档损坏时尝试从有效备份恢复。槽位显示「备份」表示正在使用恢复副本；若主档和备份都不可用，请选择其他可读取的槽位。

遇到「保存失败」时，检查浏览器是否允许网站存储，或客户端磁盘空间是否充足，再重试。客户端显示「尚未确认写入完成」意味着没有收到磁盘写入确认，**不能据此认定已经保存成功**。

自动档损坏、版本不受支持或恢复失败时，游戏会保留原档并暂停覆盖该自动槽。若当前探索仍可安全保存，先保存到一个手动槽，再明确读取该槽，按提示恢复自动保存。若提示当前探索无法安全恢复，先重新读档或重新进入街区。

更多排查方法见[常见问题](/guide/faq)。
