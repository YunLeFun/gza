# 物品图鉴

从扫把、雨伞到外卖箱里的急救包，按分类或模式查找当前游戏中的物品。

图鉴直接读取游戏的背包、武器和道具定义。3D 预览复用游戏程序模型，每次只打开一个预览；未接入或没有独立模型的物品明确提供文字外观说明。不同模式的同名物品不代表可以相互转移。

<ItemCatalog />

## 范围与模型说明

- 覆盖合作武器、城市近战工具、街区背包物品、道具赛拾取物、合作路线资源和配送货物类别
- 冲锋枪与霰弹枪目前共用后座射手的枪械造型；这里展示共用模型，不声称是各自的独立模型
- 道具赛展示游戏中实际拾取的问号箱，变大、护盾等效果没有另外虚构道具模型
- 配送货物按订单类别列出；车辆、皮肤、场景家具、建筑及无法携带的地图设施不计为背包物品，车辆请看[车辆建模图鉴](./vehicle-models)
- 预览失败或浏览器没有 WebGL 时仍可阅读全部文字资料；关闭弹窗会释放预览的模型、纹理、监听器和 WebGL 上下文
