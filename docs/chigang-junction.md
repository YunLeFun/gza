# 新港中路／赤岗路口与人行天桥

2026-10-08 依据用户提供的路口照片，细化新港中路与南侧赤岗路、北侧赤岗北路交叉口。保留原离线路网的双向分离车道、北侧转向支路和建筑占地；不把上方的步道连接到下方机动车道路。

十栋南侧条形住宅复用地图原始轮廓，增加米灰墙面、红瓦坡顶、窗笼和空调外机。无可靠楼高的住宅使用六层／17.4 m 的外观估算，不改写 OSM 高度属性。照片中的背景高楼无法逐栋确定身份，本轮不新增猜测楼盘。

## 实现与通行

`chigangSite.ts` 统一提供主跨、折转、楼梯、桥墩、街角绿篱和石墩布局；`chigangJunction.ts` 按材质合批绘制。Rapier 使用相同的有高度、可旋转实体，桥面不会产生横堵地面道路的碰撞箱。人行天桥目前是静态街景，楼梯没有加入骑行导航或虚构成可骑坡道。

街角铺装进入共用地面材质判定；自动树木、路灯和路缘避让天桥与楼梯。立面细节限 180 m、桥及小构件限 450 m、住宅轮廓限 1900 m；没有新增外部模型、图片贴图、逐灯光源或运行时地图请求。

回归见 `e2e/chigang-junction.spec.ts`：真实 Rapier 穿过两条新港中路车道及南北进口道、桥柱阻挡、铺装判定；桌面和手机实景截图、材质合批和距离剔除检查。

本轮验证：15 项相关单元测试通过，6 项天桥／大桥 E2E 通过；应用类型检查、生产构建、现有网页体积预算和发布产物检查通过。既有大桥实键骑行用例在本机使用 120 秒测试时限通过，没有改变项目预算。新增局部模型绘制批次低于 35、总三角面低于 100,000；屏幕截图另覆盖阴天步行视角和红瓦住宅正面。
