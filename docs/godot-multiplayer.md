# Godot 四人同城联机

2026-10-24 的首个原生联机切片选择 **四人同城步行／骑行**。在首页进入「四人同城」，创建或加入房间，所有玩家准备后由房主开始。每位玩家拥有自己的电驴，停稳按 F 上下车。房主退出后房间结束；首期不迁移房主。

本切片使用已有固定城市包，晴天正午。同步范围为玩家、个人电驴、步行、骑行、加速、上下车和玩家之间的碰撞；章节配送、NPC 行为、战斗、其他车辆、动态天气和流式扩城尚未进入多人规则。联机不读写个人剧情进度，返回单人后继续原存档。

## 连接方式

| 路径 | 房间入口 | 对局运行位置 |
| --- | --- | --- |
| ENet | 局域网房间，或输入可达地址及 UDP 端口 | 玩家房主电脑 |
| Steam | 好友大厅、邀请、游戏启动参数中的大厅号 | 玩家房主电脑，经 Steam Networking Sockets 通信 |
| 原生专服开发入口 | 同一地址直连界面 | Godot headless 进程，不占玩家名额 |

ENet 默认端口为 UDP 29741。公网地址直连需要端口可达；ENet 本身不提供 Steam 穿透。Steam 好友房使用 GodotSteam 自带的 `SteamMultiplayerPeer`，不依赖 Electron 的 Node 原生绑定，也不使用旧版 `sendP2PPacket`。大厅只负责发现、邀请和成员身份，游戏状态仍由房主计算。

官方专服预留相同的房间、输入和世界模拟入口。后续账号、房间分配、付费权益及运维接在准入层；当前开发入口不是已部署、已收费的官方服务。现有 Web／Colyseus 服务继续保留，它与 Godot 的 ENet 协议不互通。

## 规则与同步

房主／专服以 60 Hz 计算移动和碰撞，客户端以 30 Hz 上报输入，权威快照以 20 Hz 下发。上下车和准备等操作可靠发送；快照和连续输入使用独立的有序不可靠通道。快照压缩并限制解压大小，不解码网络对象。

单人、玩家房主和专服共享步行／上下车规则、已有骑行规则与 Rapier 查询；不同传输适配器不包含移动公式。内容包的数值与版本指纹参与握手，步行与输入边界使用共享 fixtures。服务端根据实际发送者绑定玩家，拒绝客户端位置、伪造快照、过期序号和越界输入。

超过 350 ms 没有新的输入时刹停，连接／握手超过 10 秒超时清理。Steam 准入使用底层返回的 SteamID 核对大厅成员，64 位 SteamID 使用整数与十进制字符串保存。大厅房主改变时结束原房间；开赛后关闭新成员加入。

客户端目前按相邻权威快照插值，约增加一个快照间隔的显示缓冲。尚未实现本地预测、回滚补偿、断线重连和中途加入；本地通信测试不能代表公网操作延迟。

## 开发与恢复

先完成原生工程已有的资源和物理准备。Steam 组件单独恢复，不影响不使用 Steam 的离线／ENet 开发：

```sh
pnpm godot:steam
# 新安装扩展后，让编辑器扫描一次：
godot --headless --editor --path apps/dayun-kicker-godot --import
pnpm godot:dev
pnpm godot:test:network
pnpm godot:test:network --rendered
# macOS：导出到临时目录，四个客户端连接真实发行包的专服入口
pnpm godot:test:network:package
```

GodotSteam 固定为 4.23.2，保留发行归档及各动态库 SHA-256，安装只提取 macOS／Windows 运行依赖，不启用上游自动更新插件。动态库位于 Git 忽略的缓存目录；原生声明修正了该发行包中 macOS `.universal` 文件名及 arm64 依赖匹配。恢复脚本支持复用已校验的离线归档。

Steam 初始化从 `SteamAppId` 环境变量或项目的 `steam/app_id` 读取真实 App ID；缺失时明确禁用 Steam 按钮，不自动回退到公共 Spacewar 应用。好友邀请在单人界面和联机界面均有处理；正在房间内接受另一邀请时，先显示目标房间号，由玩家离开当前房间后加入。

带 Steam 的发行构建使用 `GZA_STEAM=1` 调用现有原生导出流程，缺少或损坏依赖时失败。已安装的组件随原生导出自动带入；离线构建不要求安装它。扩展与 Steam API 依赖均计入原有包体预算。

开发专服默认只监听本机，可显式指定局域网地址：

```sh
pnpm godot:server --port=29741 --bind=127.0.0.1
```

专服等待已连接玩家全部准备后开赛；最后一位玩家离开后重置候场。当前物理扩展与运行验收支持 macOS arm64 开发环境，Windows x64 构建另行验收；Linux 专服发行仍需补齐原生物理构建。

## 验证边界

已完成本机真实 ENet 四人通信、独立房主与三个客户端、独立专服与四个客户端，以及渲染窗口中的四人角色、原生按键、上下车和窄窗口菜单检查。覆盖满员、版本不符、未准备、伪造输入、过期序号、输入超时、玩家碰撞、房主离开及个人存档隔离。

Steam 大厅回调通过适配器契约测试，GodotSteam 真实动态库与现代 peer 已装载检查。macOS arm64 发行包的 `--headless -- --server` 入口已连接四个独立客户端；包内确认 peer 注册，资源约 56.6 MiB、解包总量约 135.7 MiB，保持原有 128／768 MiB 预算。验包临时目录已回收。这不等于真实 Steam 多账号验收：游戏 App ID、不同账号的邀请／加入、跨网络中继、Windows 实机与实体手柄仍需实际环境确认。本轮不宣称公网或整机性能提升。
