# 按需加载

代码按使用时机分包，Electron 安装目录仍包含完整资源，离线时从本地协议读取。

广州城市游览与合作模式共用完整地图组装和 `createDistrictScene`；合作入口在入房后加载既有城市场景。骑行模块按真实导入关系共享，避免把赛车模拟、驾驶舱与骑行环境强制打进城市战斗入口；Vue 的翻译运行时单独分包，未使用翻译的页面只加载 Vue 自身。启动预算仍统计城市渲染和单人权威的全部必需依赖。

| 内容 | 加载时机 |
| --- | --- |
| 设置面板与画面页 | 首次打开设置 |
| 声音、操作、客户端状态 | 首次切换到对应设置 Tab |
| 动作音效合成代码 | 首次启用音频；并发调用共用一次加载 |
| 音乐文件 | 实际播放所选曲目时 |
| 广州塔室内与游客碰撞世界 | 玩家在入口选择入塔时 |
| 城市后视镜与渲染缓存 | 首次打开后视镜时 |
| 车库、平台 SDK、竞速场景美术 | 沿用既有的入口 / 操作触发加载 |

音乐偏好与媒体地址独立保存。暂停期间切歌或切换昼夜只更新偏好，继续播放时使用最新选择；普通暂停保留播放进度，重开一局在播放前归零。AudioContext 在用户操作的调用栈中创建 / 恢复，之后等待音效分包，以保留浏览器音频激活条件。下载结束前销毁音频实例不会再创建音效或恢复播放。

室内下载期间重复入塔请求不会重复创建场景，加载完成后重新检查暂停、位置、游览与巡逻状态。玩家已经离开入口或暂停时，保留外部状态。设置分包失败显示重新载入操作；室内失败显示刷新提示，车辆和其他 UI 继续可用。浏览器可能缓存失败的模块请求，恢复连接后通过重新载入页面重试。

`e2e/lazy-loading.spec.ts` 验证实际网络请求、暂停切歌、迟到的室内 / 后视镜下载及失败恢复，可针对生产预览运行。音频单元测试覆盖并发加载、销毁期间下载、失败重试、音乐选择与节奏时钟。`e2e-desktop/desktop.spec.ts` 在本地协议下打开全部设置分类、后视镜与广州塔大厅，并验证全屏及重启后的文件存档。

首屏预算按入口的完整静态依赖计算，包含动态加载的必需主模块；动态场景仍需通过首次可操作时间验收。分包改变下载时机，整体大小需要另行检查。

`pnpm verify:performance` 默认使用网页预算；`pnpm verify:performance:desktop` 检查客户端内置游戏资源。`pnpm build` 生成 Web `dist`，`pnpm verify:performance` 检查其预算；`pnpm desktop:build` 生成独立 `dist-desktop` 并自动运行客户端预算与发布完整性校验；打包后 `pnpm verify:desktop` 再检查实际离线资源、音频与完整应用体积。macOS framework 符号链接只计一次目标文件，不把多个架构的包累加。网页总量包含全部 Web 发布资源，客户端资源总量不含 Electron；完整应用预算包含 Electron。手机限速启动门禁按阶段区分：首页按钮就绪 15 秒、比赛真实首帧 35 秒、完整街区真实首帧 60 秒；条件、依据与实际体验目标见[发布验收清单](release-checklist.md)。
