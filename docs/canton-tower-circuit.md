# 广州塔滨江环线（历史方案）

2026-10-07 起，广州塔玩法统一从首页「自由骑行 · 广州城市地图」进入。在同一张城市地图中可从广州塔广场出发、滨江骑行、入塔和乘电梯游览，见 [广州塔漫游](canton-tower-visit.md)。首页不再提供独立绕塔竞速入口；云港环线和随机竞速仍是独立街机玩法。

下文保留旧 `canton` 双圈赛的实现与验证记录，用于历史纪录兼容和诊断回放，不代表当前首页玩法。此版参考高德地图公开页面观察广州塔周边街区，采用压缩街区布局。

## 地理参考与改编范围

参考路线：**阅江西路 → 广州塔路 → 艺洲路 → 艺苑路 → 阅江西路**。珠江位于北侧，广州塔与媒体港位于南岸街区，海心桥在塔西侧，对岸用简化的珠江新城天际线表达方向。

这是一条适合电动车街机竞速的游戏化闭合环线。道路宽度、转弯半径、地标位置和建筑比例经过调整，统一为单圈 1.6 km、两圈完赛；不提供真实导航、交通通行建议，也不表示测绘精度。未导入或复制高德地图瓦片、POI 数据集，不依赖运行时地图接口或 API 密钥。

海心桥只作为步行桥景观建模，没有把车辆赛道引到桥上。南岸有轨电车及轨道也作为独立路边景观，不进入玩家车道。

## 玩法与美术

- 共用现有漂移蓄能、刹车、踢击、检查点与道具规则；一圈四个检查点，两圈八个。
- 四个赛段表达阅江滨水段、广州塔路转弯段、艺洲街区段、艺苑回程段。
- 全程小地图保持北朝上，标出广州塔、北侧珠江、起点、检查点和车辆朝向；首页预览与实际行驶使用同一套路线投影。
- 固定环线、广州塔、随机种子分别保存纪录；广州塔计时与道具赛也分别保存，未完赛不写入纪录。
- 广州塔采用带扭转角的收腰格栅、分层观景平台和顶部天线；日落与夜景调整格栅彩灯、窗灯、路灯和标牌亮度。
- 海心桥连接两岸并设置引坡和栏杆；补充媒体港、赤岗塔、滨江电车、路名牌、骑楼式店铺及绿化。
- 延续奶油白、青绿、珊瑚色和深蓝车辆涂装，使新赛道与原有模型保持一致。

## 实现与性能

- `game/cantonTrack.ts`：周期三次 B 样条、弧长重采样，确保位置、方向和曲率在两圈接缝处连续。路线只在首次使用时生成并缓存。
- `game/track.ts` 的 `isCircuitTrack` 共用竞速玩法规则（现也包括点到点通勤）；`raceCourse.closed` 区分是否闭合；物理仍使用沿道路距离与横向偏移，渲染再转换到世界坐标。
- `render/cantonCircuit.ts`：固定世界坐标的装饰场景，车辆与道路使用同一路线坐标；按建筑/区域合并刚性几何，塔与对岸建筑可独立裁剪。
- `render/courseArt.ts` 按所选路线首次创建场景并复用；切图隐藏非当前场景，退出时统一释放。
- 两条固定赛道共用 `streetLampPools.ts` 的实例化路面灯光，夜景不为每根路灯创建独立动态光源。
- 首屏启动面板异步加载；赛道美术保持在比赛阶段加载，不增加首屏性能预算。
