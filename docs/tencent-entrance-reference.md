# 腾讯广州大厦正门向外视角

本轮依据腾讯广州大厦正门向外的实拍参考 `street-tencent-entrance`，优化南塔入口广场及对街街景。照片显示黄昏玻璃塔楼、国美商业裙楼的格构雨篷、成熟树冠、花坛座椅、扶手灯带与蓝色独立屏幕。原片保存在仓库外，不复制进公开资源。

地点与观察方向来自参考说明，不作为实测坐标；单张照片不能确定精确尺度。原始文件标识、私人图库入口与精确时间不进入公开记录。

## 实现

- 保留腾讯、国美、小米塔楼和道路锚点。新增国美两块裙楼与小米连接裙楼，分别替换 OSM `1458987441`、`1458987442`、`845998549` 的通用外观，保留原始占地。
- 延长已有南塔花坛，加入六株约 9–11 米的分层树冠及花坛座椅。铺装与植栽沿用经过道路和建筑裁切的前场范围，中央入口通道保持平坦、通畅。
- 侧边平台高约 0.45 米，设 8 米缓坡与两级 0.15 米中间踏步；模型和移动共用高度采样，扶手、座椅与屏幕有碰撞体。
- 国美裙楼加入商业开间、暖色檐口和折叠格构雨篷；裙楼约 18 米、雨篷顶约 22.2 米为外观估算。成熟树冠、花坛、坡道、栏杆和屏幕位置也均为近似，尚无竣工平面或高程依据。
- 国美、小米办公窗按楼层成组亮灯，黄昏便可见；前场灯带与蓝色屏幕区分色温。保持材质与纹理共享、静态合批和距离裁切，不为各开间增设点光源。
- 低层裙楼单独合批；塔楼细节用静态世界包围盒按每次渲染的相机裁切，渲染后恢复可见性，兼容后视镜和水面采样。树干与枝条去掉被地面、树冠和连接处遮住的端盖；铺装缝和屏幕面板使用平面，保留外观并减少隐藏面。
- 地图的城市游览新增「腾讯正门向外」，视点约 1.8 米，便于重复比较白天、黄昏和夜间效果。该位置与角度是近似复拍视角。

照片中央带密集灯线的远处塔楼尚未确认身份，本轮没有把这一立面强行套到某栋已知建筑上。游戏仍是按公开底图与照片制作的街景近似模型，不是测绘级复原。

## 验证

- 47 项相关单元检查通过：地块与道路净空、中央入口通行、平台／坡道／台阶高度、模型资源释放、幕墙、树木及相机裁切。
- 8 项 GPU 浏览器 E2E 通过：桌面／手机白天、黄昏和夜景，真实 Rapier 控制器上下缓坡、走台阶、栏杆阻挡与中央通道；既有腾讯入口、跨街和江侧骑行预算；游览与 GPU 上下文恢复；相邻路口黄昏与天空遮挡。
- 保持既有每帧少于 300 次绘制、少于 90,000 个三角形的入口检查；没有提高预算。
- 应用类型检查、生产构建、网页体积预算与发布产物校验通过。构建仍提示现有 Three／平台分包超过 Vite 的通用 500 kB 提示线，项目明确配置的 gzip 预算全部通过。
