# 玩法分类与道具赛

首页只保留剧情与自由模式；赛车统一收进街区 TIT 北侧的「街头赛事」。赛事准备页选择计时、道具或得分规则；得分挑战下可选经典直路或弯道试跑，再选择练习、节奏、极速冲线或连踹目标。计时与道具规则可选云港环线或随机地图，切换规则保留当前路线与地图种子。

巨大化、迷你化分岔门及其强制变身、车流清空和路线提示已移除。经典骑行经过原来的门位置时不会变身。

环线道具赛采用单人两圈、8 个有序检查点；琶洲通勤线为 3.4 km 点到点、4 个检查点。两者共用漂移、小地图和昼夜主题。在 180 米起每隔 240 米布置一排四个问号盒，每排提供四种道具，地图种子决定所在车道。经过一个盒子时拾取；库存一次容纳一个道具，持有时不会被新的盒子覆盖。驶过这一排后不会重复领取。

| 道具 | 使用效果 |
| --- | --- |
| 氮气 | 约 3 秒冲刺，最高 38 m/s |
| 护盾 | 持续 6 秒，抵挡一次车辆碰撞；抵挡后的 0.8 秒避免同一次接触反复扣伤 |
| 巨大化 | 10 秒强化踹击力度、范围，转向稍慢 |
| 迷你化 | 10 秒缩小碰撞范围、穿过车底、加快转向和踹击冷却 |

按 F 或点击道具栏使用。触屏按钮在按下时释放，因此同时按住油门和转向时第三根手指仍能使用道具；键盘和辅助技术的按钮激活也能正常使用。暂停时无法使用，道具效果计时冻结；重开清空库存和统计。

护盾保护车辆接触，驶出道路仍需要稳住方向。道具不依赖排行榜权限或购买皮肤。此版是单人道具试跑，尚未加入 AI 对手、名次或多人道具攻击。

`items.ts` 负责拾取、道具效果和护盾规则。拾取采用前后帧位置插值，避免慢帧漏掉盒子或错误领取其他车道的盒子。`itemBoxes.ts` 按需载入，只复用两排实例，共享几何体和纹理，不新增光源、刚体或阴影通道；渲染沿用道路坐标适配器。检查点和车流接地阴影通过 `raceViews.ts` 在比赛开始时加载，重开复用同一组资源；联机对手模型只在收到实时对手位置时创建。个人与异步幽灵回放已移除。

完赛纪录保存在 `dayun-kicker.items.v1.fixed.best-time` 或 `dayun-kicker.items.v1.<seed>.best-time`，广州塔与通勤线分别使用 `dayun-kicker.items.v1.canton.best-time` 和 `dayun-kicker.items.v1.commute.best-time`；与计时竞速、其他种子的地图独立。未完赛无法刷新纪录。结算显示拾取、使用和护盾抵挡次数。

验证包括拾取插值、错车道、库存保护、四种道具、护盾及接触宽限、暂停与重开、独立纪录；浏览器验证 320px 首页、真实 CDP 多指操作、F 键使用与完整两圈。移动设备结果来自 Chromium 模拟，真机手感仍需实际设备确认。
