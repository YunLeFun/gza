# dayun-kicker 美术圣经 v0.3（草案）

> 一页锁定。对照审计以此为准。带「提案」的条目等你点头后再写死。
> 日期：2026-10-28 · 依据现有仓库文档与代码色值整理，不编造色号。
> **v0.2：** 镜头定为第三人称自由世界母版，第一人称为可选沉浸；2.5D 仅辅助。
> **v0.3：** 角色开发默认 blocky；发行目标 faceted，升级时换皮不换骨架/玩法。

## 三根柱子

1. **低多边形体块** — 建筑、车辆、树、街具统一比例、轮廓、倒角与材质模块。
2. **克制的漫画动作** — 踢击用短促闪光、动作弧线、夸张物理；速度线只服务动作瞬间。网点、分镜框、拟声字留给未来的「漫画风广州」，两个现行世界都不用。
3. **温暖的广州街坊光色** — 奶油瓷砖、砖红、榕树绿、青绿遮阳篷、暖光；丧尸世界改为冷墨木刻描边。

## 镜头与可读性

- **自由世界母版：第三人称跟随**（GTA 式沙盒主视角）。角色全身剪影、载具、敌人与巷弄关系必须在此机位可读；细节预算、LOD、描边以 TP 验收。
- **第一人称：可选沉浸模式**（载具座舱为主）。从 TP 母版裁切座舱/手/仪表层，**不为 FP 另养更高模城市**。若保留垂直 FOV，沿用 **85°–95°**；旧 120°+ 仍废。前轮下沿可出画。
- **2.5D 移轴 / 俯视**：仅地图、任务选点、调试用，不作主玩法。
- 远景描边：日常世界约 **57–220 m** 淡出，更远只靠抗锯齿（TP/FP 同一套世界规则）。
- 评审机位（固定拍）：白天街口、树荫、玻璃、池水、约 300 敌人；**先以第三人称拍**，必要时加同点 FP 对照；同一机位再拍现实/丧尸 × 昼/暮/夜。

### 丧尸世界（提案，仓库尚无完整 hex）

- 环境光偏冷，白天**不要**压成夜景。
- 墨线：近黑冷墨，线宽约日常 ×1.4，中调可有排线；据点与路线保持暖/黄可读。
- 正式 hex 等你确认后再锁；在此之前用夜景分级的藏青墨 + 世界安全青 + 路线金做占位。

## 线与轮廓

- **目标：** 几何剪影优先，不为砖缝、贴图缝、高光描线。
- Godot：深度+法线墨线；日常有距离淡出。Web：目前色差描边，**提案**对齐为同等距离淡出与「弱折面不描」，或文档写明两端故意不同。
- `chunky` 的反向外壳描边若保留，只用于该造型，不与场景墨线抢权。

## 光

- 主光方向保持街坊可读：受光暖、阴影冷（现有 split tone）。
- 夜：广州阴夜——蓝天顶 + mauve/钠灯霾；车灯强度沿用现设定。
- 漫画闪光线理服务于踢击瞬间，服从「减少动态效果」开关。

## 细节预算

| 资产类 | 预算 |
|--------|------|
| 建筑 / 电驴 | 中高，**以第三人称母版为准**：模块化倒角与材质差要看得出来；FP 只加座舱层，不加密整城 |
| 交通车 / 树 / 街具 | 中：轮廓先于缝线；远景靠 LOD 降到色块 |
| 角色 **开发默认 blocky**（已锁定） | 类 Minecraft 方块头；第三人称原型与性能摸底用；同一 35 骨骨架 |
| 角色 **发行目标 faceted**（已锁定方向） | 约 6.4 头身切面人，不 Q 版；与电驴/建筑细节对齐后升级，换皮不换玩法 |
| chunky | 可选皮肤，约 4.3 头身；不与正式默认混为「同一人」 |
| FP 专用层 | 手、袖、车把、仪表；可高于世界缝线密度，但不得倒逼建筑升级 |

材质表（提案最小集）：混凝土、砖、玻璃、车漆、金属、叶、布 — 各写明明度范围与是否允许高光；禁止全部糊成同一 toon 响应。

## 目标尺寸下的可读性

- 第三人称：全身剪影、敌我、路口在跟随时可辨。
- 第一人称近景（可选）：袖管、车把、仪表不被多余几何挡住。
- 中远景：降低饱和与线权，招牌窗格不得压过路线与敌人。
- 配送黄、敌人脸手、据点青在缩小后仍须可辨。

## 禁区（Out of bounds）

- 再开第四套独立 UI 色盘。
- 把品牌饱和色大面积刷进世界墙面。
- 现实/丧尸世界使用分镜框、密集网点、拟声字（留给未来漫画世界）。
- Web/Godot 无说明地分叉描边与曝光。
- 性能专项包里夹带改色、改材质、改灯（评审与性能冻结分离）。
- 默认真人写实皮肤、或把角色退回无规范的方头直臂而不改电驴细节。
- 以第一人称或 2.5D 当自由世界主视角，或为 FP 单独养一版更高模城市。
- 三套视角各画各的资产，不走「TP 母版 → FP/俯视降级」。
