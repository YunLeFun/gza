# 陈家祠地图与解药主线

2026-10-11，剧情从普通外卖教学推进到街角疫情，再到解药密送和据点补给。陈叔在客村骑手站负责登记与接单，通过联系医院、安排街坊接应、协调粮米和工具，逐步显露他在陈家祠的话事人身份。剧情角色、疫情和秘密接应点均为虚构。

1. 登记骑手，完成「园区午餐」，练习加速、转向、刹车、看地图与停车交接。
2. 给丽园雅庭的阿婆送一碗热粥，记住她叮嘱的「轻敲门」。再接「滨江咖啡」，送餐途中在艺术博物院附近偶遇感染者，先避开危险、送完手头订单。
3. 回站接「阿婆的第二单」：同一个门口，备注变成「别按门铃，楼道里有人」。停稳交接后，陈叔安排熟识的街坊从后门接应；门口的剧情感染者退出，阿婆后续出现在祠堂接应点。
4. 回站接取密送任务，到省二医取密封保温箱，送到陈家祠南门，以「粥还热」交接解药。
5. 在南门用对讲机联系陈叔，先送粮米、再送共用维修箱。补给从祠堂周边路网上的虚构集货点领取，不需要每次返回客村。

## 据点随物资变化

| 交接进度 | 场景变化 |
| --- | --- |
| 解药送达 | 南门两侧出现救护棚、休息床、物资箱和接应街坊；救助过的阿婆来到这里 |
| 粮米送达 | 南门旁的临时厨房开锅，增加锅碗、粮米箱和供粥街坊 |
| 工具送达 | 前院两侧出现共用修车点、停放的电驴和集合骑手；师傅提起「陈先生交代过」 |

这些人物和物资是轻量程序模型，按需加载、合批绘制，留出南门交接路线。当前提供配送推动的场景变化，锅碗、工具、床和集合骑手是展示物件。四项进度由有效配送成绩派生，读档后恢复相同的据点；取消订单不会推进。已有解药存档可直接接补给，已接受过解药任务的旧存档仍可续送或重新接取。

## 地理与建模

地图沿现有中山路向西连接荔湾，提供「陈家祠 · 陈氏书院南门」导航点。地点关系参考[高德陈家祠导航](https://www.amap.com/place/B00140H88E)：中山七路、恩龙里一带，地铁陈家祠站附近；实际地图坐标采用 OpenStreetMap 的 WGS84 轮廓，避免直接混用高德 GCJ-02 坐标。

祠堂以[三路三进、九厅六院的建筑布局资料](https://www.qb.gd.gov.cn/jrqx/content/post_1246013.html)为参考，程序生成九座独立厅堂、六个可步行庭院、灰瓦坡顶、红木门窗、屋脊装饰和「陈氏书院」「聚贤堂」牌匾。大厅体量、屋顶和细节为游戏近似，没有采用导航地图瓦片、第三方模型或原照片贴图，也未制作厅内展品与展览。

`public/maps/chen-clan.json` 保留 2026-10-11 提取的 OSM 道路、原始节点、周边建筑、祠堂和广场轮廓、ODbL-1.0 许可及来源 hash。游戏沿用公共道路与自行车通行标记。中山路上四段缺失的短桥按原始节点补回；桥面与地面街道使用零高度接岸，是可玩性近似，未采集实际桥面标高，不开放高架、隧道或台阶路线。

首章物理路线验收发现地下站体 `494963802` 的轮廓覆盖中山七路。原始 OSM 标签为 `building=transportation`、`layer=-1`；导入器据此排除地下建筑的地面体量与碰撞，保留其他地面建筑。原始标签和节点记录在 `test/fixtures/chen-clan-underground-station-evidence.json`，可核对[原始 way](https://www.openstreetmap.org/api/0.6/way/494963802)。章节路线测试使用实际 Rapier 胶囊逐米通过导航线，覆盖取件、交付、返回和过江桥面。

核心资源仍为广州塔周边 5 km 地图，西向扩展另提供祠堂附近和中山路走廊；可玩围栏扩大以容纳陈家祠，地图上的范围读数随真实围栏更新。西侧其余城区尚未逐街建模，已载入路网与重点祠堂优先保证导航、步行与配送交接。
