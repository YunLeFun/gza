# 7号电动车 · 新港中路店

在自由骑行地图选择「7号电动车 · 新港中路店」，路线最后一段到门前停车位。停车后按 E、手柄 Y 或「进店改装 / 买头盔」进入，电动车留在门外，玩家步行到店内工位；离店后仍处于步行状态，可回到停车处上车。

游戏门店使用「7号电动车」名称，招牌与界面采用原创文字，不展示参考品牌名称、Logo 或宣传语。内部导航 ID 保持兼容，旧存档恢复后显示当前店名。

## 店内服务

| 服务 | 规则 |
| --- | --- |
| 套装换肤 | 预览所有套装，免费安装已解锁套装；配送任务及付费皮肤权益继续验证 |
| 车身涂装 | 冰川蓝 120、珊瑚橙 160、石墨黑 180 积分；原厂涂装免费恢复 |
| 购买头盔 | 珍珠白 80、曜夜黑与日光黄各 100 积分；购买后自动戴好 |

首次提供 200 改装积分，后续可用积分为「200 + 配送累计得分 − 购买累计支出」。消费不修改配送累计成绩；已拥有商品重复安装免费，预览不收费。涂装与头盔独立叠加当前套装，换肤后保留已安装配色。头盔颜色和佩戴状态同步骑手模型、停放车辆与路口检查。

购买记录保存在同源本地存储 `dayun-kicker.scooter-shop.v1`，同时包含于街区自动和手动快照。读取时验证商品、所属类别、所有权与累计支出；旧快照兼容没有门店字段的数据。进店期间冻结骑行、输入和游戏计时；弹窗按需加载，使用共享 UI 组件、Reka Tabs / Dialog、焦点恢复与 3D 车库预览。
