# 腾讯西侧十字路口与晚霞实拍参考

2026-10-08 使用腾讯广州大厦旁路口与晚霞的实拍参考，编号 `street-tencent-dusk`。照片仅作观察参考，没有作为游戏贴图分发；原片标识与拍摄记录保存在仓库外。

## 位置与精度

结合画面中的道路、建筑和现有 OSM 数据，判断路口为腾讯西侧的 **鼎新路 / 美居北街**，观察方向近正西。照片不能确定精确尺寸、相机高度或测绘坐标；游戏位置继续使用下述公开路网节点，原片的精确定位和时间不公开。

`tencentJunctionSite.ts` 使用原路网节点 `12927838530`、`12928079570`、`12928079569`、`12927838528` 确定两条分隔道路的交叉范围。道路中心线、建筑占地和导航拓扑保持原数据；草坪岛的椭圆形状、路缘、标线、灯杆和短柱的位置均按照片估算，并适配现有车道净空。灯组复用游戏中的 104 秒配时，与现实配时无关。

## 本轮实现

- 路口中心补为连续沥青面，中央保留低矮草坪岛和浅石色路缘；草坪分类、可见形状和分段碰撞共用布局。
- 四条分隔车道各有两侧斑马线，来车侧增加停止线；交叉范围内增加黄色网格，外侧人行道放置黑色短柱和浅色反光圈。
- 独立补入四向信号设施及中文路牌。此前通用规则只处理至少包含一条主干路的路口，遗漏了这里两条 `unclassified` 道路的交叉。
- 清除该路口内自动生成的树木和直线路缘，保留外围行道树及路灯；岛体和短柱避开现有车道。
- 黄昏配色改为蓝灰上空、灰粉过渡与地平线附近的淡金色；街区西侧更暖，云层使用连续的长条薄云和深浅云带。玻璃的缓存天空反射同步使用新配色，路灯在黄昏稍早显现。
- 云和光晕绘制到远平面，保留远建筑遮挡；光晕随天空光源位置更新，阴天隐藏。昼夜切换复用已有纹理与材质，无新增逐灯光源或渲染捕获通道。
- 城市游览增加「腾讯旁十字路口」，从路口东南上方朝西观察。18 m 观景高度和构图是游戏估值，不代表原片相机高度。

入口：自由骑行 → 地图 → 城市游览「腾讯旁十字路口」→ 黄昏（18:30）。开启跟随本机时间时，先在时间设置中关闭跟随，才能选择手动时段。

照片里的弧形下沉入口、每盏灯的具体样式、远处完整的珠江新城天际线尚未按实景重建；玻璃反光及手机镜头星芒没有作为世界物体加入。当前仍是基于道路数据和照片的美术近似。

## 验证

`tencentJunction.test.ts` 核对实际地图全部附近道路的净空、草坪与沥青分类、四向信号、街道装饰预留及局部模型的合批、距离裁剪和资源释放。`skyFinish.test.ts` 检查光晕跟随、阴天隐藏及跨时段资源复用。

`e2e/tencent-dusk.spec.ts` 检查桌面与手机的真实游览截图、90,000 三角形和 400 次调用上限、四条车道双向 Rapier 通行、草坪岛阻挡，以及远处建筑不被云层覆盖。
